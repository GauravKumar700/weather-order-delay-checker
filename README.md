# 🌦️ Weather-Aware Order Delay Checker

A Node.js script that checks live weather conditions for pending e-commerce orders and automatically flags likely delivery delays — with AI-generated, personalized apology messages for affected customers.

Built as part of an AI Intern assignment focused on concurrent API calls, resilient error handling, and practical AI integration.

## ✨ What it does

1. Reads a local `orders.json` "database" of pending orders.
2. For each order, looks up the current weather in that city — using a **two-step process**: city name → coordinates (Geocoding API), then coordinates → live weather (Weather API).
3. All cities are checked **concurrently**, not one by one.
4. If the weather is `Rain`, `Snow`, or `Extreme`, the order is marked `"Delayed"` and a **personalized apology message is generated by an AI model** (Groq) — e.g.:
   > *"Hi Alice, your order to New York is delayed due to heavy rain. We appreciate your patience!"*
5. Invalid or unrecognized cities are logged as errors but **never crash the script** — every other order still gets processed.
6. `orders.json` is updated in place with the final statuses and apology messages.

## ⚙️ How it works

### Concurrent fetching
```js
export async function fetchAllWeather(orders) {
  return Promise.all(orders.map(fetchWeather));
}
```
All orders' weather requests fire at the same time instead of sequentially, so total run time is roughly the time of the *slowest* single request, not the sum of all of them.

### Two-step weather lookup
```
City name  →  Geocoding API  →  { lat, lon }  →  Weather API  →  current conditions
```

### Resilient error handling
Each city's fetch is wrapped in its own `try/catch`. A failure for one city (e.g. an invalid name) is logged and that order is skipped — it never rejects the whole `Promise.all` batch or crashes the script.

### AI-generated apologies with a safety net
The apology message is generated live via [Groq's](https://groq.com) chat completion API. If the API key is missing or the request fails for any reason, the script falls back to a simple template message instead of crashing.

## 🚀 Getting started

### 1. Clone and install
```bash
git clone https://github.com//weather-order-delay-checker.git
cd weather-order-delay-checker
npm install
```

### 2. Get your API keys
- **OpenWeatherMap** (free): https://openweathermap.org/api
- **Groq** (free): https://console.groq.com/keys

### 3. Configure environment variables
```bash
cp .env.example .env
```
Then edit `.env`:
```
OPENWEATHER_API_KEY=your_openweathermap_key
GROQ_API_KEY=your_groq_key
```

### 4. Run it
```bash
npm start
```

## 🔒 Security

- No API keys are hardcoded anywhere in the source.
- All secrets are loaded from `.env`, which is excluded via `.gitignore`.
- `.env.example` is provided as a safe template.
